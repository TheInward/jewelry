# En Route WordPress 本地复刻工程

第一阶段开发中。当前实现项链分类、175 条 WooCommerce 商品、商品页模板、搜索、属性筛选、排序、收藏、购物车和 WooCommerce 结账基础；已补充邮箱注册、登录、退出和账户中心。首页、商品页和结账 HTTP 200，加购及跨请求会话正常。已在浏览器对照桌面分类页和登录/注册页；移动端真机及全站逐像素验收仍未完成。完整差异见 `reference/对标差异分析-2026-11-01.md`。

## 运行

```sh
npm install
npm start
```

本地地址：http://127.0.0.1:9400

阿里云开发预览：http://39.106.108.70:8080/jewelry/ （已放行 8080，按用户要求取消预览密码，直接显示商品）。顾客账户：http://39.106.108.70:8080/jewelry/my-account/ 。服务器环境与目录见 `deploy/DEPLOYED.md`。

WordPress Playground 在 Node 中提供 PHP 和 SQLite，无需先安装 PHP/MySQL。主题位于 `theme/`，可迁移到正式 WordPress 的 `wp-content/themes/enroute-study`。本地运行时使用临时数据库，重启会按 blueprint 重新导入；订单和账户目前仅用于开发，不应作为正式数据存储。

## 已实现与边界

- 读取 2026-11-01 公开项链商品信息：名称、价格、图片 URL、标签、在售状态。未导入客户评价、品牌长文或私人数据。
- 图片仍引用原站 CDN，后续替换 `_study_images` 为自己的媒体库资源。视频清单待全站盘点。
- 首版导入为简单商品，原站多变体需后续建立 WooCommerce variable product 并核对库存规则。
- 当前首页暂时使用项链分类模板；导航其他类目尚未独立实现。
- 语言/国家入口目前只显示基准市场，未安装翻译或多币种组件。
- 未接任何收款账户，未启用真实支付。结账、运费及税费必须后续配置。
- 继续禁止搜索引擎索引。远端预览访问密码已按用户明确要求取消，顾客登录仅用于自己的账户、地址和订单。
