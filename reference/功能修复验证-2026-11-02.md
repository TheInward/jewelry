# 分类、账户、语言与货币修复

部署目标：https://mrnobodys1.sg-host.com/ 。日期：2026-11-02（北京时间）。

## 修复结果

- 原先所有导航链接都指向项链，查询也没有分类条件。现使用独立分类页面和 WooCommerce taxonomy 查询，按参考站公开集合成员关系导入；53 个分类/系列共 757 个独立商品，保留原有 175 个商品 ID 和账户。
- 主分类：项链 175、手链/脚链 113、戒指 145、耳环 190、畅销 141、新品 138、Shop All 719。不同系列存在合理重叠，不按名称猜测分类。参考接口当前为空的 Rustic Soul 与 The Odyssey 保留空状态。
- Collections 改为独立系列目录；搜索和收藏跨分类读取，不受当前列表限制。
- 修复详情、购物车、结账等非列表页缺少筛选 DOM 时的脚本崩溃。购物袋修改请求排队，数量按钮等待响应后恢复。
- 账户入口显示登录/我的账户；真实邮箱注册、登录、退出、订单、地址、资料及密码恢复表单可用。
- 14 种语言：英语、波兰语、西班牙语、法语、德语、荷兰语、意大利语、瑞典语、日语、韩语、葡萄牙语、希腊语、捷克语、匈牙利语。主要主题界面使用本地词典，原生 WooCommerce 使用官方语言包；719 个商品保存了参考接口提供的 13 种其他语言名称。其余商品无对应翻译时保留原名，不将菜单切换冒充全量内容翻译。
- 使用免费 WCML 5.6.3 的服务器多币种引擎。当前初始化 55 种货币；国家/地区选择与语言独立保存。商品、运费、免邮门槛、购物车与原生结账使用同一后台换算。
- 汇率取自 ExchangeRate-API 开放接口，保存在数据库，每日 WordPress cron 刷新；请求失败保留此前汇率。页面提供来源署名，不把接口汇率数据提交 Git。主题缺少币种插件/配置时退回 USD。
- 采用 WooCommerce 原生 shortcode 购物车和结账，避免默认 Blocks/Store API 与自定义购物袋使用不同的货币上下文。原 Blocks 内容保存在页面私有 meta 及数据库备份中；只保留页头一个货币选择入口。
- 符合条件时仅保留免邮方式，避免金额满足免邮却仍收固定运费；购物袋改为如实提示结账计算运费。
- HTML 使用 private/no-store，清理 SiteGround 旧动态缓存，防止旧入口或其他访客的语言/币种串用。

## 验证

自动验证脚本：`deploy/verify-catalog-localization.mjs`、`deploy/verify-accounts.mjs`。不提交付款或真实订单，临时购物车清空，临时顾客删除。

已核对主要分类及子分类的完整商品成员 ID，而非只比较商品数量。美元 27 的测试商品在 2 件购物车下：USD 54、HKD 423.60、EUR 48.38、JPY 8506、GBP 40.34；这是验证时的报价，后续汇率更新会变化。商品价、购物袋和原生结账总额一致；另验证美国地址下免邮及不同访客购物车隔离。

Safari 实际打开戒指列表、切换法语及港币，并确认商品名称与金额变化；详情页购物袋按钮可打开弹层。

Google/Facebook 登录、密码重置邮件实际送达、订阅邮件/折扣弹窗、账户同步收藏、所有商品变体及尺寸库存、全部政策/营销文案翻译、多语言 SEO URL、移动端真实视口和 100% 视觉对照仍未完成。本次没有开启搜索收录，也未更新阿里云旧预览。
