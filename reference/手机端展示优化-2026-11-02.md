# 手机端展示优化 — 2026-11-02

参考：（原参考链接已移除） 。目标：https://mrnobodys1.sg-host.com/ 。先以相同390×844视口检查两站首页、项链分类和Waterdrop商品页，再调整模板及767px以内的展示。

## 展示调整

- 顶部公告40px、导航37px；手机首页导航叠加横幅。语言/国家控件移入菜单；空购物车不显示0。滚动后导航固定、恢复白底。
- 引入参考站当前使用的Simvoni字体；保留开发阶段参考素材，后续随品牌资源替换。
- 首页分类改为三项可见的横向列表，补齐金色、银色、套装专题图与相应商品轨道；商品列表、标题和价格按手机视口调整。
- 分类页双列商品、大图、排序入口、全屏筛选与应用/关闭控件；颜色点链接到实际商品颜色，不假造商品选项。
- 商品页全宽图库、细条图片指示、滑动切图、收藏入口；颜色点和套装价格卡片与WooCommerce原生选择器联动。
- 价格使用WooCommerce已计算的当前币种金额。修复清除规格后价格残留；桌面仍显示原生选择器。
- 手机页脚改为黑底，调整品牌、订阅、帮助/信息顺序；订阅表单增加隐私同意项。手机输入字号至少16px，避免iOS输入缩放。
- 修复顶部公告遮挡菜单、菜单层级、767px仍使用双栏详情、移动端价格原始区间文本残留等问题。

## 验证

运行 `npm run verify:mobile`，需要本机安装Google Chrome。

360、390、430、767px均通过：公告/导航尺寸，菜单打开关闭及语言/币种入口，订阅弹窗，商品双列，筛选开关，真实规格ID/51.30美元套装价格联动，清除规格价格还原，详情单栏，无横向溢出。

1440px桌面通过：手机专属分类/菜单隐藏，桌面分类与原生商品选择器保留；无页面JavaScript错误。没有提交邮件、订单或付款。

对照截图与最终截图在本地 `.runtime/mobile-review/`；390px主要截图为 `after-home-top.png`、`after-home-full.png`、`after-collection.png`、`after-product.png`。

## 边界

这是对已检查页面的手机布局与交互优化，不代表所有商品、语言、登录后状态及第三方模块已逐像素验收。真实支付、会员运营和正式政策的未完成项沿用前次记录。参考站Google评价浮层等第三方组件没有伪造。
