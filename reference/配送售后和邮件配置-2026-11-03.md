# Seleneith 配送、售后及邮件（2026-11-03）

## 已确认规则与线上实施

- 商品折后金额低于 US$100：标准运费 US$7.99；达到 US$100：免标准运费。排除运费和税费后判断，WCML 转换运费与门槛，不能把 EUR100/JPY100 当成免邮门槛。
- 按顺序：美国本土48州及DC；AK/HI/PR；欧盟27国及英国；CA/AU/NZ；东南亚；WooCommerce原生其余世界。东南亚包括 BN/KH/ID/LA/MY/PH/SG/TH/TL/VN，排除缅甸。美国军邮区域落兜底，实际物流承运能力仍需商家与渠道核实。
- 销售选项为 all_except：IR/KP/SY/MM/VE/YE/AF；配送继承销售允许国家。原生结账及 Store API 加入服务端拒绝，运费接口不给排除国家返回运费。不依赖额外拦截插件。
- 各区域总时效12–25工作日：从下单到收货，包含处理及运输；非保证到达日。偏远、清关、节假日可能延误，物流扫描可能间断。
- 运费不含未在结账明确收取的进口税费（DDU/未预付进口税费）；收件人可能需向海关或承运商支付。不会复制对标站的税费由卖家承担安排。
- 自愿退货：收货后14天内提出，再在通知后14天内寄出；非质量问题由买家承担退货直达运费。质量/错发单独处理；不通过绝对拒退条款排除法定权益。
- 参考对标站：100天制造缺陷额外保修，通常每件一次免费替换，替换不重新起算；正常磨损、误用等不属额外保修，保留法定权益。
- 丢件：超过25工作日未收到即可联系客服发起查询；运输途中确认丢失提供补发或退款。已签收未收到须调查，不一概免除卖家责任。
- 未虚构已签约的物流渠道、具体仓库或退货地址。承运商以实际发货信息为准；退货地址由客服在申请时提供，商家仍需准备可用地址。当前没有物流商API自动下单或自动同步物流轨迹。

购物车与结账页增加12–25工作日总时效、可能有进口费用的提示及配送政策链接。

线上页面：/pages/shipping-policy/、/pages/return-policy/、/pages/shipping-return/、/pages/start-a-return/；页脚分开链接配送和退货政策，FAQ已同步。

**用户已确认四封均进入 seleneith@163.com 收件箱，本轮端到端投递验收通过。** 此结果不保证所有邮箱服务商都能收取，将来若更换主机或发信方式需重新验证。
